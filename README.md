# 05 - Advanced To-Do List: Async & UI Pro 

Este proyecto representa un salto significativo en mi dominio de JavaScript. He implementado una aplicación de tareas que no solo gestiona datos locales, sino que también consume recursos de APIs externas y ofrece una experiencia de usuario (UX) pulida con modales y modos de visualización.

## 🛠️ Retos Técnicos Superados:
- **Asincronía (Promises & Async/Await):** Implementación de consumo de API REST para cargar datos externos de forma eficiente.
- **Manejo de Modales:** Creación de una interfaz de edición mediante ventanas emergentes con efectos de desenfoque (`backdrop-filter`).
- **Control de Propagación:** Uso de `e.stopPropagation()` para evitar conflictos entre eventos de elementos anidados.
- **Dynamic Theming:** Sistema de "Dark Mode" basado en clases dinámicas y manipulación del Body.
- **Lógica de Estado:** Contador dinámico de tareas completadas basado en la presencia de clases en el DOM.

## 🎨 CSS Avanzado:
- Animaciones con `transition` y `transform`.
- Efectos de profundidad con `box-shadow`.
- Layouts flexibles y responsivos con Flexbox.

##  Tecnologías:
- **JavaScript Moderno (ES6+)**
- **Fetch API**
- **CSS3 Avanzado**
- **HTML5**
